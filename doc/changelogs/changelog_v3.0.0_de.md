# v3.0.0

**Wichtig:** Dieses Release setzt mindestens **v2.7.0** voraus. Wenn du noch eine ältere Version verwendest, führe das Update bitte über das Installationsskript aus (dasselbe wie bei der Erstinstallation, siehe [Setup Script ausführen](https://github.com/floppyFK/kittyhack#2-setup-script-ausf%C3%BChren)) und nicht über das Update in der Weboberfläche.

## Neue Features

- **Statistik**: Neuer Tab *Statistik* mit Ein- und Ausgängen, Beuteerkennungen, Zeit drinnen/draußen und typischen Aktivitätszeiten - auch pro Katze und für verschiedene Zeiträume.
- **Bewegungssensor als Bestätigung bei Kamera-Einlass**: Optionale Einstellung unter *Konfiguration*. Wenn die Kamera Katzen erkennt, öffnet sich die Klappe nur, wenn auch der äußere Bewegungssensor auslöst. Hilfreich, wenn Sonne oder Spiegelungen manchmal eine Katze vortäuschen.
- **Hinweise ausblenden**: Manche Hinweise können mit *Nicht mehr benachrichtigen* ausgeblendet werden. Unter *Konfiguration* kannst du sie später wieder aktivieren.

## Verbesserungen

- **Einfacheres Menü**: Eine neue Katze wird jetzt auf der Seite *Katzen verwalten* hinzugefügt. Die WLAN-Einstellungen findest du im Tab *System*.
- **Besser am Handy**: Die Weboberfläche bleibt auf dem Smartphone zuverlässiger verbunden.
- **Schnellere Erkennung**: Die Katzen- und Beuteerkennung auf der Kittyflap ist nun etwas performanter.
